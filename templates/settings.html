📤 Update Database

עדכוני מסד הנתונים מתבצעים מקומית באמצעות daily_sync.py

📖 איך לייצא נתונים מטלגרם

  1. פתח את Telegram Desktop (לא ניתן מהאפליקציה הניידת)
  2. לך ל-Settings → Advanced → Export Telegram data
  3. בחר את הקבוצה/צ'אט שברצונך לייצא
  4. סמן JSON כפורמט הייצוא
  5. לחץ Export והמתן לסיום
  6. העלה את קובץ result.json כאן
💡 טיפ: המערכת תזהה אוטומטית הודעות כפולות ותוסיף רק הודעות חדשות. אין צורך לדאוג מהעלאת אותו קובץ פעמיים.

💻 עדכון דרך שורת הפקודה

לקבצים גדולים, מומלץ להשתמש בשורת הפקודה: 

# עדכון database קיים עם JSON חדש
python indexer.py new_export.json --db telegram.db --update

# יצירת database חדש
python indexer.py result.json --db telegram.db
